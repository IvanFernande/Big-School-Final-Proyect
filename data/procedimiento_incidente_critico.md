# Procedimiento de Gestión de Incidentes Críticos

## Objetivo
Definir los pasos obligatorios ante una incidencia clasificada como crítica para minimizar el impacto en el negocio.

## Pasos Iniciales
Ante una incidencia crítica, el agente debe:

1. Clasificar la incidencia como severidad crítica.
2. Evaluar el impacto en usuarios y sistemas.
3. Determinar la urgencia de actuación.
4. Validar los SLA aplicables.
5. Iniciar el proceso de escalado inmediato.

## Registro en el Ticket
Toda incidencia crítica debe incluir como mínimo:
- Descripción clara del problema.
- Impacto detectado.
- Urgencia estimada.
- Evidencias disponibles (logs, capturas).
- Hora de detección y acciones iniciales.

## Escalado
Las incidencias críticas deben escalarse directamente a Nivel 2 o Nivel 3 según disponibilidad.
